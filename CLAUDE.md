# Claude Code Guidelines

## Scope of Rules
- These rules apply strictly to **new code changes and additions**.
- Existing code and existing comments should not be modified or removed solely to satisfy these rules.

## Commenting Guidelines
- **Single-line comments only**: Only single-line comments are permitted.
- **Source Code Files**: Comments are allowed **only before function signatures**. Do not add inline comments or comments inside function bodies.
- **Test Files**: Comments are allowed **only before test cases**.

## Commit Guidelines
- **No Co-Author attribution**: Do not include Claude as a co-author (e.g., `Co-authored-by: Claude`).
- **No Session References**: Do not include references to Claude Code sessions or session metadata in commits.
- **Commit Title Limit**: The commit title (subject line) must have a maximum of 50 characters.
- **Commit Description Limit**: The commit description (body) must have a maximum of 300 characters.
